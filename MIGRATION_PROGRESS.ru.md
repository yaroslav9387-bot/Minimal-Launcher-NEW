# Minimal Launcher — рабочий журнал миграции

## Исходная точка

Работа ведётся по сохранённому архиву `Minimal-Launcher-redesigned.zip`, потому что свежую папку пользователя нельзя получить из-за лимита вложений. В архиве могут отсутствовать последние локальные исправления пользователя.

## Сделано

- Подключена новая оболочка Minimal Launcher с тёмным интерфейсом и зелёными акцентами: главная, библиотека, моды, серверы, локальные друзья, настройки.
- Главная использует реальные профили; запуск, создание и импорт сборок вызывают существующие механизмы лаунчера.
- Новая вкладка модов фиксирует источник Modrinth и использует прямой Modrinth API; установка использует существующий installer flow.
- Новая вкладка серверов сохраняет адреса локально и вызывает штатный Quick Join.
- Онлайн-раздел друзей честно заменён локальным списком ников; чат/звонки/приглашения не имитируются.
- Frontend API для старых Millida-only сервисов заблокирован; аккаунты Millida мигрируются в локальные офлайн-профили при допустимом нике.
- Rust mirror/proxy отключён: Minecraft/Java/loader/Modrinth ресурсы не должны проксироваться через Millida.
- Удалены Millida-домены из Tauri CSP, updater endpoints очищены, Rust fallback updater endpoints пусты.
- Телеметрия отключена.
- Чужой Microsoft Entra client ID удалён. Используется только `MINIMAL_LAUNCHER_MS_CLIENT_ID`; без собственного ID вход Microsoft сообщает, что не настроен.
- Обновлены русские статусные документы.

## Проверки, выполненные в этой среде

- `src-tauri/tauri.conf.json` успешно разбирается как JSON.
- Tauri app config содержит название `Minimal Launcher`, identifier `net.minimal.launcher`, updater endpoints пусты.
- Статически проверены CSP и Rust updater fallback: Millida endpoints в них отсутствуют.
- Проверено, что `src-tauri/src/engine/core/mirror.rs` возвращает только исходный URL и не создаёт proxy/fallback URL.
- Проверено, что telemetry guard всегда выключен.

## Что не удалось проверить

- `tsc -b` запущен, но остановился до проверки исходников: в архиве нет установленных зависимостей и отсутствуют type definitions `bun` и `vite/client`.
- Bun и Cargo/Rust toolchain недоступны в этой среде.
- Не выполнены frontend tests, Rust tests, production build, Tauri Windows build и запуск `.exe`.

## Ограничения, которые нельзя скрывать

- Microsoft login требует регистрации собственного приложения Microsoft Entra и сборки с `MINIMAL_LAUNCHER_MS_CLIENT_ID`.
- Онлайн-друзья, чаты, голос, приглашения, облако и хостинг требуют собственного backend и relay. Пока доступны локальные контакты и обычное подключение к введённому адресу сервера.
- Автообновление выключено, пока не будет собственного подписанного manifest и signing key.
- CurseForge не подключён в новой оболочке; вкладка модов работает через Modrinth.
- В legacy-коде остаются названия и части модулей Millida для совместимости/дальнейшей миграции. Они не должны использоваться новой оболочкой; массовое удаление до анализа вызовов сломало бы проект.
