# Minimal Launcher — заметки форка

Этот проект является форком исходного кода Millida Launcher, распространяемого по GPL-3.0-only. Сведения об авторских правах, лицензия и NOTICE сохранены.

## Что изменено в первой итерации

- Название приложения и заголовок окна заменены на Minimal Launcher.
- Добавлен собственный логотип и базовые иконки для Windows.
- В настройках вида добавлена настройка бокового меню: изменение порядка пунктов, скрытие ненужных пунктов и сброс к исходному виду.
- Пункт «Друзья» нельзя скрыть.

## Что ещё требуется до публичного релиза

- Завершить замену всех фирменных материалов Millida и проверить сторонние лицензии/ассеты.
- Заменить bundle identifier и внутренние пути хранения с миграцией существующих данных.
- Заменить или отключить API Millida: вход Millida, друзья, чаты, скины, рейтинг, хостинг и обновления.
- Зарегистрировать собственное приложение Microsoft Entra ID и Discord (либо отключить соответствующие функции).
- Подготовить собственный сервер для сетевых функций друзей, если нужен онлайн-список, приглашения и чат.
- Проверить сборку Windows и провести тестирование на чистой системе.

Пока это исходный код для разработки, а не готовый установщик для распространения.
